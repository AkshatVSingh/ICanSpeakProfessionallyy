How it works

Local rewriting engine

This version removes the fake SaaS claims from the original page and replaces them with a real browser-side rewriting workflow. It detects intent, urgency, rough phrases, deadlines, and message type, then builds a polished version using local language rules and tone templates.

01

Intent detection

Classifies requests, apologies, complaints, follow-ups, payments, rescheduling, leave, and general updates.

02

Phrase upgrading

Converts casual or aggressive wording into workplace-safe language while preserving the core meaning.

03

Local history

Saves recent rewrites in localStorage only, so there is no backend account or server database.
